# Sizzle & Bun — Artisanal Smash Burgers

A responsive, polished landing page for **Sizzle & Bun**, an artisanal smash burger restaurant. Built with clean semantic HTML5, modern CSS3, and vanilla ES6 JavaScript. Designed for high performance, smooth interactions, full accessibility, and zero-dependency static deployment on Vercel.

## 🍔 Features & Highlights

- **Visual Palette**: Warm charcoal background (`#121110`, `#1a1918`), cream text & surfaces (`#faf7f0`, `#f3ede2`), mustard yellow accents (`#f4a218`), and tomato red action highlights (`#d83a27`).
- **Hero Burger Illustration**: 100% handcrafted HTML/CSS layered smash burger featuring sesame brioche bun, secret sauce, crisp curly lettuce, ripe tomato slices, melted farmhouse cheddar with cheese drips, flame-seared Angus patties with crispy lacy edges, pickles, caramelized onions, and floating feature tags.
- **Featured Menu**: 3 signature items with pricing, detailed descriptions, flavor badges, and quick-order integration:
  - *The Golden Smash* ($14.50)
  - *Truffle Smokehouse* ($16.95)
  - *Fiery Red Diablo* ($15.75)
- **Quality & Craft Section**: Prime Heritage Angus 80/20 blend, 24-hour fermented brioche buns, scratch-made sauces, and key stats.
- **Opening Hours & Location**: Structured schedule with live status badge, address, phone, email, and directions link.
- **Interactive Ordering Modal**: Accessible pickup & delivery builder with live total calculation, quantity adjustments, and toast feedback.
- **Accessibility & Interactions**:
  - Skip to main content link
  - Keyboard-accessible modal & mobile navigation with `Escape` key listeners and focus trapping
  - Respects `prefers-reduced-motion` media queries
  - High-contrast `:focus-visible` rings
  - IntersectionObserver scroll-reveal animations with graceful fallbacks
- **Deployment Ready**: Configured for static hosting on Vercel with optimal caching and security headers via `vercel.json`.

## 🚀 Local Preview & Testing

Serve locally with any static server:

```bash
# Using Python
python3 -m http.server 8000

# Using Node.js
npx serve .
```

Open `http://localhost:8000` in your browser.
